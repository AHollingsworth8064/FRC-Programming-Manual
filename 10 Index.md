Here collected are many of the terms in this book along with their definitions.

Abstraction - Moving common functionality into a dedicated function or class.
Auto/autonomous - Period of the match where the robot may not receive human input.
Arguments - The data passed into a function.
CAD - Computer Aided Design; one of the subteams; building the robot in a virtual environment.
Conditional - A piece of code that will only run if a *condition* is true; if/else statement.
Constructor/`init` - A function which sets up a class, and sets its values. A constructor is a function with the same name as the class.
FRC - First Robotics Competition; as opposed to FTC, or FLL.
Function - Code that can be "called" from any point in the program; a thing which transforms input data into output data.
IDE - Integrated Development Environment, for example IntelliJ Idea.
Inheritance - Creation of a class which has all the elements of a "base" class, but also its own additional elements.
Iteration - Looping through all the items in a list, one by one. 
List - A sequence of objects, all of the same type. Objects may be added or removed from the list.
Array - A sequence of objects, with a fixed size. The list may be mutated, but its size may not be changed.
Loop - Such as `while`/`for`; Repeats code until a condition is true.
Mechanism - Collection of parts grouped into a single functional unit.
Method - Like a function, but tied to a specific class; a function "inside" a class.
Null - Absence of the expected value in a variable.
Object - A single instance of a class, stored in memory; the data stored in a variable.
Operator - Like a function, but is a symbol that appears between to values (such as the `+` in `1 + 1`).
  (Arithmetic) - Performs a math operation, such as `+`, `-`, `*`, `/`, and `%`.
  (Logical) - Such as `and`/`&&`, and `or`/`||`, generally used when both sides of the operator are `boolean`s.
Parameters - Specifies the data the function takes as an input.
Teleop/Teleoperated - Period of the match where the robot is controlled by a human.
Scope - The collection of values/variables available at a certain point in a program; 
  (Global) - The values/variables available at any point in the program.
Type/Class - Specifies a data structure, and its associated functions.
  (Enum/Enumeration) - A type that can be one of mutliple types.
  (Data) - A class whose purpose is to store simple data.
Type Conversion - When one type is converted to another type.
Value - A place where data will be stored when the program is run, that cannot be changed after it is first initialized.
Variable - A place where data will be stored when the program is run, that can be changed after it is first initialized.
