Imagine spinning a motor for one second. In a perfect world, the motor would always stop at the same point. In reality there is always variation, and over time that can add up. And yet, robots can perform precise movements with little to no error. How do they do that? Well, it's thanks something called sensors. 

Sensors are pieces of hardware that allow our code to get information about the physical world. In FRC, there are many types of sensors we can use, but I'll only focus on a few.

## Encoders 
Encoders are pieces of hardware that measure physical motion, like rotation, and convert it into information that our code can use. Typically, we use them with our motors so that we can keep track of things like how far it has moved or how fast it is moving.

Some motors have built-in encoders.

## Gyro 
A robot typical has one intake, so it must face a specific direction to retrieve game pieces. But how is it supposed to know which direction it is facing? Well thanks to gyros, it is a lot easier. After all, it's a devise that measure how fast something is rotating.  With that, our code can determine how far it has rotated and know which direction the robot is facing.

## Beam Break
Let's say we want our shooter to start spinning when ever a game pieces is available to shoot. By using a beam break to check if a game pieces passed a certain point we can do that.
